# Audit pasca-Tahap 6 — 30 Agustus 2026

Empat auditor paralel terhadap build produksi yang berjalan, dengan tiga
fixture karya di dataset. Bukan pembacaan kode: tiap temuan di bawah punya
perintah yang mereproduksinya. Yang tidak punya, ditandai **DUGAAN**.

**Batas kejujuran.** Semua angka diukur terhadap `next start` di kontainer ini,
Chromium, viewport tetap. Bukan data lapangan, bukan perangkat nyata, bukan
skor Lighthouse. TTFB terukur 8–10 ms — itu localhost, bukan hosting.

---

## 0. Pola yang muncul di keempat domain

Bukan satu pun cacat di bawah ini ditemukan oleh gate. Semuanya lolos
`bun run check`, `bun run build`, `build-storybook`, dan
`CI=true bun run test:e2e` — 123 test hijau di atas situs yang memotong judul
utamanya sendiri di locale Indonesia.

Tiga sebab strukturalnya, dan ketiganya bisa ditutup:

1. **Suite e2e hanya merender satu viewport, 1280×720.** Tidak ada satu pun
   ukuran ponsel di CI. Untuk situs studio komisi yang trafiknya kemungkinan
   besar dari Instagram, lapisan verifikasi ini tidak pernah melihat tampilan
   yang dilihat mayoritas pengunjung.
2. **axe tidak pernah menjalankan aturan WCAG 2.2.** axe-core 4.13 tidak
   mengaktifkannya secara default; keempat pemanggilan di repo ini memakai
   konfigurasi polos. Klaim "axe bersih" di roadmap §1.5 benar secara harfiah
   dan menyesatkan secara praktis.
3. **Tidak ada gate yang membaca CSS terkirim atau header respons.** Aturan
   motion #1–#4 sepenuhnya bergantung pada review manusia; `Cache-Control`
   tidak pernah dilihat siapa pun.

Dan satu temuan yang lebih tajam dari ketiganya: **metode verifikasi gambar di
Tahap 5 secara struktural tidak bisa melihat cacat yang ditemukan sekarang.**
Tabel "Dirender / Natural / Diminta" memakai `naturalWidth`, yang pada `<img>`
ber-srcset adalah nilai _density-corrected_ — ia mengukur `sizes` terhadap
dirinya sendiri dan **selalu** melaporkan "pas". Gate yang salah bentuk lebih
berbahaya daripada tidak ada gate, karena ia menghasilkan ✅.

## Tier 1 — dilihat pengunjung sekarang

### 1.1 Judul `/id` terpotong di setiap lebar ≤768px

`overflow-wrap: break-word` tidak mengurangi kontribusi **min-content** sebuah
elemen; hanya `anywhere` yang begitu. Jadi kotak `<h1>` dipaksa selebar kata
terpanjang ("memperhatikan"), melewati tepi viewport, lalu dipotong diam-diam
oleh `overflow: clip` milik hero.

```
/en vw=390  h1 w=356.8  longest "Commissioned"  needs 348.0  -> fits
/id vw=390  h1 w=375.3  longest "memperhatikan" needs 375.3  -> OVERFLOWS
/id vw=320,360,375,414,430,768 -> OVERFLOWS semua
```

`hero.module.css:87-92` sudah mencatat bug seperti ini pernah terjadi dan
menyebut jaring pengamannya "should never fire". Jaring itu memang tidak
pernah bisa menyala.

Gate gagal dua lapis: tidak ada viewport ponsel, dan bahkan kalau ada, cek
`scrollWidth > clientWidth` tetap lolos karena `overflow: clip` menyembunyikan
luberan dari metrik dokumen.

**Lokasi** `vault/blocks/hero/hero.module.css:93` · **Perbaikan** kecil

### 1.2 Karya seninya di-upscale di layar retina dan ponsel

`SanityImage` memanggil `urlForImage(image).width(maxWidth)` — jadi `maxWidth`
dipakai sekaligus sebagai plafon piksel Sanity **dan** sebagai lebar layout.
Pada DPR ≥ 2 browser meminta `w=1920`/`w=2560` tetapi hanya menerima 704/1440 px.

```
/en dpr=2  css 691×864   need 1382px  delivered  704×880  = 0.51x
/en dpr=2  css 1398×874  need 2796px  delivered 1440×900  = 0.52x
rimbun cover dpr=2  need 2246px  delivered 1440×900       = 0.64x
/en @390 dpr3       need 1070px  delivered  704           = 0.66x
```

Plafonnya nyata, bukan pilihan browser: `w=1920`, `w=2048`, dan `w=2560`
semuanya mentok di 1440×900 — srcset di atas itu palsu.

Situs yang seluruh proposisinya adalah reproduksi lukisan menampilkan lukisan
itu di setengah resolusi pada MacBook, iPad, dan setiap ponsel modern. Tidak
terlihat sebagai bug; terlihat sebagai lukisan yang lembek.

**Lokasi** `components/ui/sanity-image/index.tsx:71` vs `:74` · **Perbaikan** kecil

### 1.3 Tiap halaman karya dikirim tanpa description dan dengan kartu OG generik

```
$ curl -s .../en/work/rimbun | grep -oE '<meta (name|property)="(description|og:description|og:image)"[^>]*>'
<meta property="og:image" content="https://.../opengraph-image.png"/>
```

Tidak ada `meta description`, tidak ada `og:description`, dan `og:image`-nya
kartu wordmark Arth — bukan lukisannya. Padahal `schemas/project.ts:68`
memberi tahu editor bahwa cover "used in the work grid **and as the OpenGraph
image**".

Penyebabnya: `generateSanityMetadata` menurunkan description dari
`document.excerpt`, dan `excerpt` hanya ada pada `article` — bukan `project`.

Tahap 6 memperbaiki canonical, `og:url`, dan `og:locale` lalu berhenti di situ;
`canonical-sweep` hanya membandingkan ketiganya.

**Lokasi** `lib/utils/metadata.ts:122,241,254` · `queries.ts:137-159` · **Perbaikan** sedang

### 1.4 three.js dikirim ke setiap pengunjung `/en`, termasuk yang tidak pernah melihat kanvas

245.6 KB gzip / 931 KB raw sebagai `<script async>` di HTML awal — 47% byte
skrip halaman itu.

```

desktop, prefers-reduced-motion: three downloaded = YES  <canvas> = 0
iPhone 390x844 dpr3:             three downloaded = YES  <canvas> = 0

sama, nol byte — dan itulah yang benar-benar terkirim di HTML SSR.

Tahap 5 mengukur `/en/ai` (turun 47%) lalu berhenti; `/en` tidak diperiksa
ulang setelah opt-in dipasang.

**Lokasi** `app/[locale]/page.tsx:152` · `lib/webgl/components/canvas/index.tsx:27-32` · **Perbaikan** sedang

### 2.3 Skip-link inert di setiap halaman

Menekan Enter tidak memindahkan `document.activeElement`, tidak menggeser
scroll, dan `:target` tetap null. Tab berikutnya jatuh ke logo, bukan ke dalam
`<main>`.

Dua penyebab bertumpuk: `<main id="main-content">` tanpa `tabindex="-1"`, dan
skip-link memakai `Link` next-intl (client router) sehingga navigasi fragmen
native tidak pernah terjadi. Gagal WCAG 2.4.1 — satu-satunya mekanisme bypass
yang situs ini punya.

Tes yang ada hanya memeriksa `href` dan visibilitas; tidak pernah menekan Enter.

**Lokasi** `app/[locale]/layout.tsx:199-206` · `components/layout/wrapper/index.tsx:151` · **Perbaikan** kecil

### 2.4 `/id/ai` sepenuhnya berbahasa Inggris di bawah `lang="id-ID"`

37 dari 37 string terlihat identik dengan `/en/ai`. Begitu pula setiap halaman
404 dan error di kedua locale. Teks skip-link juga hardcoded Inggris — padahal
kunci `nav.skipToContent` sudah ada di kedua file pesan
(`"Lewati ke konten utama"`) dan **tidak pernah dipanggil dari mana pun**.

axe lulus karena `html-has-lang` hanya memeriksa atributnya ada dan valid.
`/id/ai` ada di sitemap, jadi mesin jawaban meng-index dua salinan identik
sebagai konten dua bahasa.

**Lokasi** `app/[locale]/ai/page.tsx` (nol next-intl) · `app/[locale]/layout.tsx:204` · **Perbaikan** sedang / kecil

### 2.5 Editor yang mengisi bahasa Indonesia dulu merusak sisi Inggris

Fallback `coalesce` hanya satu arah — ke EN. Diuji dengan GROQ literal:

```

dengan Tahap 3.

**Lokasi** `queries.ts:101-106` · `schemas/project.ts:32` · **Perbaikan** kecil–sedang

## Tier 4 — hygiene

- **GSAP (26,8 KB gzip) dan `@sanity/client` (21,7 KB) masuk ke `/en/work/*`** yang tidak meng-opt-in ke `gsap` maupun `webgl`. Keduanya dimuat setelah hidrasi lewat `import()`, jadi penghitungan `<script src>` Tahap 5 melewatkannya. `@sanity/client` juga terkirim ke `/en/ai`, rute yang komentarnya sendiri menyatakan "server-only end to end".
- **Blur placeholder bukan blur karyanya**: gradien putih generik identik untuk setiap gambar, 6,7 KB inline per halaman karya, dan `<animate>`-nya terbukti tidak menghasilkan gerakan. Sanity mengirim LQIP asli di `asset->metadata.lqip` — belum diambil.
- **`fetchpriority="high"` tidak ada di elemen LCP** maupun preload-nya; satu-satunya `fetchpriority` di HTML adalah `low` milik preload skrip Next.
- **Tipe dokumen `navigation` hidup di Studio tapi tidak dirender di mana pun** — editor mengisinya (judul, tautan sosial, logo) dan tidak ada yang berubah. `page` dan `article` adalah sisa starter yang otomatis masuk sitemap begitu dibuat. Tiga dari lima tipe yang dilihat editor tidak dijelaskan di panduan.
- **`studioSettings` singleton hanya berdasarkan niat** (`structureTool()` polos, query ambil `[0]`), dan field "Default SEO"-nya diproyeksikan tapi tidak pernah dibaca — `/id` mengirim `SITE.description` berbahasa Inggris.
- **Tidak ada cara menyatakan karya itu lukisan/mural/ilustrasi**, padahal `SITE.services`, `knowsAbout`, dan `description` menyebut ketiganya. `medium` adalah prosa bebas terlokalisasi, tidak bisa difilter.
- **Halaman detail mengambil seluruh daftar karya** hanya untuk menghitung "next project" (2266 → 1530 byte kalau diproyeksikan seperlunya). Payload tumbuh linear terhadap jumlah karya.
- **25 referensi `app/(site)` dan 11 `(examples)` masih tersisa**, termasuk yang membentuk perilaku: `RESERVED_PATHS` masih mencadangkan `/sanity`, rute yang sudah dihapus. `AGENTS.md:249` dan empat README menunjuk file yang tidak ada.
- **93 export tidak pernah dirujuk** (mayoritas typegen dan skrip; ~15 layak dihapus). `@sanity/language-filter` ada di `dependencies` dengan nol impor.
- **`/api/draft-mode/enable` tidak punya rate limit** — tebak-paksa preview secret tak dibatasi. (`revalidate` dan `disable` sudah benar.)
- **`/en/studio` dan `/en/contact`** juga soft-404, konsekuensi arsitektur single-page; layak redirect ke anchor-nya.
- **`lastmod` sitemap dihitung per request** — berubah tiap kali di-fetch.

## Yang diverifikasi LULUS

Disebutkan karena beberapa di antaranya baru pertama kali diuji dengan skrip,
bukan dengan mata.

- **`prefers-reduced-motion`** — kriteria keluar roadmap §1.5. Nol elemen
  tertinggal di `opacity:0` di `/en`, `/id`, `/en|/id/work/rimbun`. `data-reveal`
  langsung `visible`. LULUS.
- **Restraint** — 2 typeface, 3 bobot, 3 durasi, 3 kurva (semua token), 3 warna
  teks + 2 latar, monokrom. Standarnya dua/tiga/satu/tiga/empat. Terpenuhi.
- **CLS 0,0000** di semua rute, semua viewport, termasuk 390×844 dpr3 dan
  setelah scroll penuh. Perbaikan Tahap 5 §2 kokoh.
- **Tidak ada kebocoran secret ke bundel klien** — token 180 karakter nol hit di
  284 chunk `.next/static/`. (Ada di `.next/cache/turbopack/*.sst`, cache build
  yang tidak disajikan — perlu diperhatikan kalau `.next/cache` di-persist di CI.)
- **Endpoint API menolak dengan benar** tanpa kredensial: `revalidate` 503→401,
  `draft-mode/enable` 401, `disable` 403 pada cross-site.
- **Katalog terjemahan utuh** — 38 vs 38 kunci, nol selisih; 6 nilai identik
  semuanya kognat yang sah.
- **axe (wcag2a/2aa/21a/21aa/22aa + best-practice)** pada 10 URL: **nol
  pelanggaran selain `target-size`**, sama persis di `reducedMotion:'reduce'`.
- **AVIF benar-benar terkirim** dengan `Vary: Accept`; negosiasi bekerja.
- **Font**: hanya subset latin, tepat 2 woff2 (56,9 KB), keduanya immutable dan
  di-preload, nol CLS dari swap. 8 woff2 lain ada di disk tapi tidak dilayani.
- **Aturan #1 bersih** (0 `cubic-bezier` mentah di luar file token), **#3 bersih**
  (0 `300ms` hidup), **#12 hampir bersih** (semua grid produksi `minmax(0,1fr)`).
- **Urutan fokus masuk akal**, nol elemen fokus-tapi-tak-terlihat, nol focus trap.
- **Cakupan story `vault/`** patuh: 12 dari 13 folder, yang tanpa story bukan
  primitive.

## Yang tidak bisa diukur, dinyatakan eksplisit

- **Tidak ada latensi jaringan.** TTFB 8–10 ms adalah localhost. Temuan 1.4 dan
  `fetchpriority` dampaknya soal antrean jaringan dan waktu CPU parse — byte dan
  atributnya terukur, konsekuensi waktunya adalah penalaran.
- **Tidak ada Lighthouse, throttling CPU/jaringan, atau perangkat nyata.**
  "iPhone 390×844 dpr3" adalah viewport + DPR + UA Chromium, bukan Safari dan
  bukan CPU ponsel.
- **Kenaikan 17–28 KB per rute sejak Tahap 5 tidak diatribusikan** — butuh
  membangun ulang commit lama, yang akan mematikan server yang diminta hidup.
  Jumlah `<script>` identik, jadi tidak ada modul baru masuk graf.
- **LCP tidak disebut regresi.** Sebaran run-ke-run di mesin ini lebih lebar
  daripada selisih terhadap Tahap 5.
- **Boot `/studio`** — lihat 2.8.
