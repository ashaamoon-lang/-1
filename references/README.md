# references/

Architectural observations from projects whose **code cannot be used**.

Every repository documented here ships **no `LICENSE` file** and is therefore
all-rights-reserved (verified 2026-08-29 — see `docs/PROVENANCE.md` §5).

**The line these notes stay on.** Recorded here: which libraries a project
depends on, what that implies about its architecture, and which of those
decisions we should or should not copy. Not recorded here: their source code,
in any quantity, paraphrased or verbatim.

A dependency list is a public fact. An architectural decision — "render 3D on
a worker thread" — is an idea, and ideas are not copyrightable. The
implementation is, and none of it is in this repository.
